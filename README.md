# 麓庄回声 Echoes of Lushan

一个纯前端网页解谜游戏，故事发生在深秋的山中庄园——麓庄。

你收到一封没有署名的信，回到一年前逃离的地方。随着探索深入，你将揭开一场持续三年的情绪实验真相，并在最后做出自己的抉择。

## 游戏特色

- **多场景探索**：一层、二层、地下室、庭院、后山，25 个可探索场景。
- **多种解谜玩法**：拼图、音序校准、数字转盘、接线配对、开锁。
- **丰富的线索系统**：物证柜、人物档案、推理笔记、时间轴、任务思维导图。
- **双结局**：报警结案 / 后山见陆苍。
- **全程语音旁白**（依赖浏览器 Web Speech API）。
- **纯前端实现**：无需服务器，双击 `index.html` 即可游玩。

## 如何运行

1. 下载或克隆本仓库。
2. 用浏览器打开 `index.html`。
3. 推荐使用 Chrome、Edge 或 Safari。

## 图片资源说明

所有图片均已从原图床下载至本地 `assets/` 文件夹，游戏不再依赖任何外部链接，可永久稳定运行。

## 技术栈

- 原生 HTML / CSS / JavaScript
- Web Audio API（环境音效与 BGM）
- Web Speech API（语音旁白）
- SVG（楼层地图与接线小游戏）
